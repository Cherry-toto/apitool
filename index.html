使用文档和教程

快速开始

本API调试工具无需注册，打开即可使用。只需按照以下步骤即可快速开始测试API接口：

  1. 在URL输入框中输入要测试的API地址
  2. 选择HTTP请求方法（GET、POST、PUT、DELETE、PATCH）
  3. 根据需要添加查询参数、请求头和请求体
  4. 点击"发送"按钮发送请求
  5. 在响应区域查看返回结果

功能说明

HTTP请求方法

支持多种HTTP请求方法，每种方法适用于不同的场景：

  • GET - 获取资源，通常用于查询数据
  • POST - 创建新资源，通常用于提交表单数据
  • PUT - 更新整个资源，通常用于修改数据
  • DELETE - 删除资源，通常用于删除数据
  • PATCH - 部分更新资源，通常用于修改部分数据

查询参数

查询参数是URL中问号后面的键值对，用于过滤或排序数据。您可以：

  • 手动添加多个查询参数
  • 使用"导入参数"功能批量导入参数
  • 参数会自动添加到URL中

请求头

请求头包含关于请求的元数据，常用的请求头包括：

  • Content-Type - 指定请求体的媒体类型
  • Authorization - 包含认证信息
  • User-Agent - 标识客户端信息
  • Accept - 指定客户端能接受的响应类型

请求体

请求体包含要发送给服务器的数据，支持以下格式：

  • JSON - 结构化数据格式，适合复杂的数据结构
  • Form Data - 表单数据格式，适合文件上传和简单表单
  • Raw - 纯文本格式，适合自定义数据格式

响应信息

响应区域显示服务器返回的详细信息：

  • 状态码 - HTTP状态码，如200表示成功，404表示未找到
  • 响应时间 - 请求从发送到接收的总耗时
  • 数据大小 - 响应数据的字节大小
  • 响应内容 - 服务器返回的实际数据

复制请求功能

点击"复制请求"按钮可以将完整的请求信息复制到剪贴板，包括：

  • 请求方法和URL
  • 查询参数
  • 请求头
  • 请求体
  • 响应数据

这个功能特别适合与后端工程师沟通调试问题时使用。

使用技巧

  • 使用"导入参数"和"导入请求头"功能可以快速添加多个参数
  • 查询参数会自动添加到URL中，无需手动编辑URL
  • 响应区域支持滚动，可以查看完整的响应内容
  • 支持中英文界面切换，方便不同语言用户使用
  • 所有功能都在浏览器中运行，数据不会发送到我们的服务器
